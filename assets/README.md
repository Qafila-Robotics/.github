# Organisation assets

- `icon.svg` — master square icon (five caravan dots, maroon leader leftmost and largest), copied
  from the brand guidelines. Decorative only, no text, so it renders without fonts.
- `qafila-icon-1024.png` — 1024×1024 export of `icon.svg`, used as the organisation profile picture
  and in `profile/README.md`.

The canonical brand assets (all logo versions, fonts, tokens and additional sizes) will be added by
the brand export from the private package `@qafila/brand` in `qafila-platform` (`packages/brand`).
Until then this folder holds only what the organisation profile needs. Never redraw the logo — use
the exported files.
