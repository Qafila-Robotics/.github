# Qafila Robotics · قافلة للروبوتات

**One fleet. Every robot. · قافلة واحدة. كل الروبوتات.**

---

Qafila Robotics builds **Qafila Fleet**, one platform that connects humanoids, quadrupeds, drones
and ground vehicles so a single operator can see, control and coordinate every robot from one
screen — whatever network each robot is on. Robots keep their fast, safety-critical behaviour on
board; the platform adds shared knowledge, coordination and a central AI model.

تبني قافلة للروبوتات منصّة **قافلة** (Qafila Fleet): منصّة واحدة تربط الروبوتات البشرية والرباعية
والطائرات المسيّرة والمركبات الأرضية، ليستطيع مشغّل واحد أن يشاهد كل الروبوتات ويتحكّم فيها وينسّق
مهامها من شاشة واحدة، مهما كانت شبكة كل روبوت. تبقى السلوكيات الحسّاسة للسلامة على الروبوت نفسه، بينما
توفّر المنصّة المعرفة المشتركة والتنسيق والنموذج الذكي المركزي.

### What the platform does

- **Connect** — any robot, any network, joins one private encrypted fleet.
- **See** — live video, audio, status and position for every robot on one map.
- **Coordinate** — describe a mission once; the platform assigns each step to the robot best able to do it.
- **Learn** — what one robot observes is stored and shared, so the whole fleet knows it.

### Safety first

When the link drops, the robot stops and holds — never "keep going". Every motion command expires,
new missions need an operator's approval, and every action is logged. We describe how the robots
stop; we do not promise zero risk.

### Where we are

The platform is in active development, built in Qatar for the Gulf, in Arabic and English. A pilot
programme is opening. We publish what is proven and mark what is still being built.
